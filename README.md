## About

This project was submitted as part of a college competition — a digital poster celebrating Onam, the harvest festival of Kerala.

The focus was on layout composition, color palette, and cultural aesthetics — all built from scratch using HTML and CSS without any design tools or frameworks.

---

## What went into it

- Choosing a color palette that reflected traditional Onam visuals
- Structuring the layout to feel like a poster, not a webpage
- Handling typography and spacing manually in pure CSS

---

## Context

- **Type:** College competition entry
- **Festival:** Onam — Kerala's harvest festival
- **Approach:** Pure HTML & CSS, no frameworks

---

## Reflection

Building something with a visual and cultural purpose was a different challenge from building functional web pages. This project pushed me to think about design intent — not just code that works, but a layout that communicates something.
